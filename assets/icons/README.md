# VenTapes icons

The cassette marks in this directory were created specifically for this private learning fork so the experiment has a distinct identity. They are not the upstream Mixtapes artwork and do not represent an official release.

The original Mixtapes icon concept was sketched by [Jakub Steiner](https://gitlab.gnome.org/jimmac) and rendered by [gnoman](https://gitlab.gnome.org/gnoman). Their work remains credited in [`../../CREDITS.md`](../../CREDITS.md) and in the upstream project.

The scalable application, development, symbolic, and action SVGs are the
sources for the VenTapes mark. The Windows `.ico` files under `windows/` are
generated from the application SVG.
